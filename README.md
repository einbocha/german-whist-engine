# german-whist-engine
A deterministic game engine / state machine for the card game [German Whist](german_whist_rules.md).

# Setup of source code
1. check the prerequisites
2. `pixi install` creates the environment
3. `pixi shell` to enter the environment
4. `cargo test`, etc. should now work

## Prerequisites
- pixi
